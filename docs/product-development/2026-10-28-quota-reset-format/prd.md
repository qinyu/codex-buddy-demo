## 范围

- 当前已核实行为：固件 `src/main.cpp` 中 `resetText` 和 `resetTimeText` 按剩余时间分档格式化；非固件代码负责提供/归一化重置时间，但尚未找到既有非固件倒计时格式化入口。
- 本次拟在 `tools/codex_usage_ble_bridge.py` 增加一个纯格式化函数，输入剩余秒数，返回可读字符串；函数独立可测，不新增 UI 或设备协议字段。
- 时间展示规则：大于等于一天显示为 `Dd HHh`（天数 + 两位剩余小时）；大于等于一小时且小于一天显示为 `Hh MMm`（小时 + 两位剩余分钟）；大于零且小于一小时显示为 `Mm`；小于零显示 `Reset due`。正数按整分钟向下取整；小于一分钟显示 `0m`。
- 允许修改：`tools/codex_usage_ble_bridge.py` 及其对应的 `tools/test_provider_quota.py` 测试。

## 验收

- AC-001：输入 `90061` 秒时，函数输出为 `1d 01h`，不把总小时数显示成 `25h`。
- AC-002：输入 `7261` 秒时，函数输出 `2h 01m`。
- AC-003：输入 `3599` 秒时，函数输出 `59m`；输入 `59` 秒时输出 `0m`。
- AC-004：输入负数时输出明确的 `Reset due`，且不显示负时间单位。
- AC-005：格式化函数只在非固件 Python 侧新增；本切片不得修改 `src/`、固件工程配置、设备协议或刷写/设备操作。
