# 业务需求澄清记录：Agent Hub 状态同步

## 原始需求与背景
开发者桌面常常同时运行多个编码助手（Codex CLI、Cursor、Claude Code）。
需要通过本地 Hook 统一收集各 Agent 的生命周期事件，并通过 BLE 同步给 StickS3，在大屏中进行多智能体轮播。

## 目标用户与触发场景
- **用户**：同时使用多个 AI 编程工具的高频开发者；
- **场景**：桌面工具开始编码、等待确认或发生错误时，Stick 伴侣即时切换对应 Agent 的宠物表情与用量。

## 边界约束与非目标
- **约束**：BLE 广播每包数据严格限制在 31 字节以内，超过部分通过轻量特征值写入；
- **非目标**：本次只支持现有 StickS3 硬件端展示，不扩大到项目里不存在的客户端。
