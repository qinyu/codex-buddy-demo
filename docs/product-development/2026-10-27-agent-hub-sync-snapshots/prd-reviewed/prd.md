## 背景与问题陈述
解决多智能体并发工作时，开发者难以一眼感知各 Agent 当前工作状态的痛点。

- **Journey 1：智能体注册与状态上报**
  - **US-01**：作为开发者，当我启动 Cursor 或 Codex 时，Stick 屏幕右上角数字自动加 1。
    - **AC-01**：接收到 Hook 事件后，`active_agents` 计数器正确递增并在 500ms 内更新；

- **Journey 2：状态表情切换**
  - **US-02**：当活跃 Agent 发生 `busy` 或 `attention` 时，硬件切换至专属表情。
