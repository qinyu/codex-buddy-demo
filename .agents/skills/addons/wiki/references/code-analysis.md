# 可选代码分析

本页由Wiki按需加载，不是另一个skill。内部Python CLI仍叫 `code-wiki`，引擎为CodeGraph。基础知识不依赖该运行时。

## 查询

沿用入口的授权边界与本次取证。`user_declined`只答获准文档，直接返回。其余图任务先选一个入口：公开CLI/MCP由agent单独调用状态接口；已就绪的内部CLI由其自身检查公开状态，无需在外部再探测。入口首次明确不可用就结束本轮图取证，不换入口重复确认。公开入口在获准仓库调用 `codegraph status`（或MCP等价状态接口），取得结果后只选一条分支：

- **不可用**（未初始化、索引错误或依赖缺失）：记录原文，返回“图证据不可用，具体原因仅以公开结果为准”。有源码许可则转回入口的源码取证；没有则返回缺口。到此结束图查询，本节后面的可用查询步骤不执行。另有建图/同步授权才转独立的“建图与恢复”节。
- **可用**：进入下面的“可用查询”。判断依据是 `initialized` 或公开可用性说明，退出码0本身不足以证明可用。参数错误可查help纠正；它与明确不可用不同。

### 可用查询

公开入口按任务调用 `explore`、`callers`、`impact`。过期图标注过期，用获准源码补当前事实；另获同步许可才更新。状态与查询分两次调用，不用 `&&` 预排查询。结果够回答当前问题就返回，不为补全命令清单继续调用。

需要内部CLI的结构化结果时，确认环境与依赖已经就绪，再禁止同步环境地执行：

```bash
uv run --no-sync --directory <wiki-skill-dir> code-wiki query --repo <git根> --question <问题> --kind search
```

环境缺失就退回已安装CodeGraph或获准源码。普通查询不创建虚拟环境、不下载或安装依赖；默认 `uv run` 会隐式准备环境，不能当作只读命令。

`search`处理业务话，`cite`处理符号/文件，`impact`处理调用影响。结果最多5条hit，带repo与path:line；未覆盖范围进uncovered。坏响应、缺图、依赖缺失、无命中分别报告，不能静默将错误当空结果。必要时回查授权源码。

MCP或shell都是可接受调用路径，以实际调用和返回内容证明，不能只说“已接入”。图的新鲜度、节点、边与调用者只通过CodeGraph公开接口核验：用 `status` 查看待同步变更，用 `node` / `files` / `callers` / `impact` 查询；源码补充当前事实。图库文件由引擎独占读取；agent禁止直接读取其字节、文件头或私有表，包括 `file`、`xxd` 等诊断工具。`file`会读取文件头，不是只看文件名或stat元数据。`query_ready`只表示可尝试，实际结果才能证明成功。

## 建图与恢复

仅用户选择增强且授权建图时执行。先检查版本、现有索引与Git排除规则；`.codegraph/`及查询缓存是本地派生信息，不进入Git。已有被跟踪派生文件先提示，不擅自移除Git记录。

```bash
codegraph init <仓库>
```

仅授权增量更新时用 `codegraph sync`，再公开status和任务查询核对结果；不以全量重建替代sync。

在获准仓库直接调用CodeGraph建图，按本机help选择参数；需要非交互时仅对已授权的本地建图使用 `--yes`。先在各仓库排除 `.codegraph/`，保留已有.gitignore内容。旧 `code-wiki init/ensure/onboard` 会写章程与清单、改变遥测设置，仅供历史兼容，不用于Wiki建图。建图不改AGENTS、全局遥测、MCP注册、LSP或凭据。

缺CodeGraph先报告缺依赖，用户选择安装才提供方案并执行；已有CodeGraph不因Python缺失另装Python。不默认传--yes-install。记录样本语言、文件规模、冷建/增量/重建时耗与结果，不将小样本结论外推大仓。建图失败保留可用知识，不伪装ready。

材料拉取与章程定稿由Setup负责；旧内部ensure/onboard命令保留为实现资产，但不是Wiki默认执行路线。已有仓库不重拉，不默认生成SSH密钥、配置LSP或修改章程。图更新不得借机扩展这些授权。

## 模块梳理

按 `module-map.md` 与 `llm-wiki.md` 执行：先草稿，再检查未回答的边界问题，用户确认后编为活页。图关系是证据，不是业务模块命名的最终裁决。已有主题页优先更新，导航以链接接入。

旧引擎数据处理参考 `migrate-legacy.md`；删除/重建必须明确授权，与普通查询分离。
