# 小程序 UI 切片

识别：`app.json`、`project.config.json`、`*.wxml`/`*.wxss`，或同类平台配置。先确认微信/支付宝/抖音等平台、原生/uni-app/Taro、基础库版本、分包、组件库和审核约束；不得跨平台猜 API。

- 原型：覆盖授权、登录态、网络异常、空态、加载、成功与返回路径；遵守导航栏、tabBar、胶囊区和安全区。
- 实现：复用现有页面/组件、请求封装、storage 与埋点；权限 API、隐私弹窗、订阅消息必须按目标平台真实能力处理。
- 测试：沿用现有 Jest/Vitest/平台自动化；纯逻辑可单测，平台生命周期与授权用已有 mock 或开发者工具证据，不伪造真机结果。
- 验证：记录静态检查、单测、开发者工具预览/真机检查的实际结果；上传、提审、发布必须由用户明确授权。
