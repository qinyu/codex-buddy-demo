# 外挂：Stitch

与 impeccable 对等：本仓不维护 Stitch MCP/SDK。默认 zip 不含 `stitch-prototype`。HTML 原型（`product-prototype`）仍是常规阶段。

## 探测

本机 skills 目录存在 `stitch-prototype/SKILL.md`，或用户在本切片明确点名 Stitch 路线。未命中：原型只用 HTML 路线，或把原型标 `Not Applicable`（按 `run-mode.md`）。不要提示去装 Stitch。

## 挂点

原型阶段。用户选 Stitch 且已命中：请用户执行 `$product:stitch-prototype`（人触发，编排不代点）。失败不自动改走 HTML，等用户修 MCP 或批准改路线。

读 `DESIGN.md` / 现有 UI 的约束与 impeccable 页相同：没证据不自创视觉体系。
